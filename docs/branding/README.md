# Tokenograph icon studies

Five hand-authored vector directions, made on 2026-09-05. The owner selected **1, Context
Loop**; final SVG/PNG/ICO assets and usage notes are in [`assets/brand/`](../../assets/brand/).
The other studies are retained as alternatives. This is not a release announcement; no
changes have been made to the panel or its wordmark.

1. **Context loop** — an open context ring, three accounting rows, and an incoming token.
   Emphasizes the bounded window and reused history.
2. **Ledger** — three measured rows inside a single bracket. Emphasizes attribution and
   accounting; the most typographic abstraction.
3. **Trace** — a stepped activity signal between a point and a token. Emphasizes session
   timing and the tool as an instrument.
4. **Aperture** — four window corners around measured columns. Emphasizes seeing inside
   the context window.
5. **Ligature** — custom lowercase `tg` geometry with a returning `g` stroke. Emphasizes
   the name rather than a literal chart.

All SVGs in `concepts/` use a 64×64 viewBox, transparent backgrounds, no fonts, no external
resources, and the panel's blue (`#2f8ff5`) and mint (`#7ee3b8`). Each includes a title and
description. Their geometry is original to these studies; trademark clearance has not
been performed.

The local review sheet at `.lavish/icons.html` shows each in color and monochrome, with
16/24/32-pixel samples and an app-tile preview. That generated review directory is ignored
by Git. The chosen mark now has favicon, monochrome, and app-icon variants. A wordmark
lockup and integration into the actual panel remain separate, optional work.
